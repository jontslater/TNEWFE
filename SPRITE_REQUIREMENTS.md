## 🎨 SPRITE REQUIREMENTS PER CLASS

### **Minimum Required Animations:**
Each class needs sprites for:
- **Idle Animation** (standing/breathing)
- **Attack Animation** (basic attack)
- **Defend/Block Animation** (taking damage/blocking)
- **Ability/Spell Animation** (class-specific ability)
- **Death Animation** (optional but recommended)

**Total Animations per Class:** 4-5 animations

### **Sprite Specifications:**
- **Format:** PNG with transparency
- **Size:** Varies by browser source requirements
- **Style:** Consistent art style across all classes
- **Resolution:** High enough for browser source display

## 💡 COST OPTIMIZATION STRATEGIES

### **1. Phased Development**
- Start with most popular classes (tanks + top 5 DPS)
- Add remaining classes as revenue allows
- **Benefit:** Get sprites in-game faster, generate revenue sooner

### **2. Asset Store/Pre-made Sprites**
- Search Unity/Unreal asset stores for sprite packs
- May find class-themed sprite packs
- **Cost:** $50-200 per pack (could cover multiple classes)
- **Benefit:** Significantly cheaper, but may need customization

### **3. Single Artist vs. Multiple Artists**
- **Single Artist:** Consistent style, but slower (9+ weeks)
- **Multiple Artists:** Faster (3-5 weeks), but need style guide
- **Recommendation:** Start with 1-2 artists, expand if needed

### **4. Sprite Templates/Reuse**
- Create base sprite templates per role
- Reuse animations where possible (all tanks use similar attack patterns)
- **Benefit:** Reduces cost per class by 20-30%
